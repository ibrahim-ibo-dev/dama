# Native Dama verification

Native source: [`75b3580`](https://github.com/ibrahim-ibo-dev/dama/commit/75b35802340a007163500be7aeb73c4fcaec20a6). Verified on 29 October 2026.

## Android

- Flutter 3.38.0 / Dart 3.10, JDK 17; release APK built successfully on Windows.
- Local deliverable: `artifacts/dama-android.apk` (excluded from source control). File size and SHA-256 are in [`dama-android-build.json`](dama-android-build.json).
- APK signature verified with Android `apksigner`. It uses this machine's Android Debug certificate for private testing, rather than a Google Play distribution key.
- Android 7.0 / API 24 or newer; targets API 36. Universal APK includes arm64-v8a, armeabi-v7a and x86_64.
- Both bundled font license files were checked inside the actual APK.

## iOS

The macOS job built the current native source for the iOS simulator successfully, packaged `Runner.app`, and uploaded the `dama-ios-simulator` artifact. See the [native build run](https://github.com/ibrahim-ibo-dev/dama/actions/runs/40942070957).

The simulator ZIP is not an installable iPhone IPA. Installing on an iPhone needs a Mac/Xcode signing setup and the owner's Apple identity/provisioning. No Apple credentials or store publication were used. No physical Android phone or iPhone was attached to this Windows machine.

## Rules, state and crossplay

- 61 Flutter tests cover the rules, bot, UI, online protocol, secure-session abstraction, reconnect and stale-response races. The rule contract compares all legal turns and resulting state against 167 canonical positions generated by the web engine.
- Flutter static analysis reports no issues. The existing website's 27 tests and TypeScript check also passed.
- The real Dart HTTP client and a web-shaped HTTP client completed 35 assertions against the local backend, and another 35 against `https://dama.ibrahim-eng.dev` with shared Redis.
- Each crossplay run tested two creation directions, moves from both players, identical boards, chat identity, spectators, capacity, rejected stale moves, agreed draws, rematches, swapped colors and stable scoring. All eight created seats were left after each run; no existing room was changed.
- Native bot analysis was exercised through a real Flutter compute isolate. Browser QA covered entering a bot game, legal moves, bot replies and the live board-only view.
- Phone widget checks cover 390px and 320px layouts, including enlarged text. Native fonts, brand, colors, entry cards and board styles follow the existing website.
